Defination list

HTML:
HTML is the standard markup language used to create and structure the content of a web page. It uses tags (like headings, paragraphs, and links) to tell a web browser how to display text, images, and other elements.
CSS
CSS stands for Cascading Style Sheets. It is a style sheet language used to describe the presentation, visual layout, and formatting of a document written in a markup language like HTML.
JavaScript
JavaScript (JS) is a lightweight, cross-platform, and interpreted programming language primarily used to create dynamic and interactive content on the web. Alongside HTML (which structures web content) and CSS (which styles it), JavaScript serves as the third core technology powering the modern World Wide Web.
